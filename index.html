❓ Help
💌
Message পাঠাবো কিভাবে?
Home পেজে গিয়ে Message Box এ লিখুন এবং "SEND MESSAGE" বাটনে ক্লিক করুন। নাম, ফোন ও FB দেওয়া Optional।
🕶️
পরিচয় গোপন রাখবো কিভাবে?
"Use Default Hidden Identity" Checkbox এ Tick দিন। Name, Phone, FB সব Automatically Hidden হয়ে যাবে।
🔔
Notification কিভাবে পাবো?
Website খুললে Notification Permission এর Popup আসবে। Allow করলে Admin Reply করলে তাৎক্ষণিক নোটিফিকেশন পাবেন।
📥
Reply কোথায় দেখবো?
Reply আসলে একটি সুন্দর Popup দেখাবে। এছাড়া Menu থেকে "Receive History" তে সব Reply দেখতে পাবেন।
🆔
User ID কি?
প্রথমবার Visit করলে একটি 3-Digit Unique ID তৈরি হয়। এটি Browser এ Save থাকে। Admin এই ID দিয়ে আপনাকে Reply পাঠায়।
🔒
Message কি Secure?
হ্যাঁ! সব Message Encrypted API এর মাধ্যমে পাঠানো হয়। কোনো Secret Key বা Token Frontend এ থাকে না।
